# Password Generator 🔐

A simple Python-based Password Generator that creates strong and secure passwords based on user-defined criteria.

## 📌 Features

- Generate random passwords
- Customize password length
- Includes:
  - Uppercase letters (A-Z)
  - Lowercase letters (a-z)
  - Numbers (0-9)
  - Special characters (!@#$%^&*)
- Easy to use and beginner-friendly

## 🛠️ Technologies Used

- Python 3
- Random Module
- String Module
